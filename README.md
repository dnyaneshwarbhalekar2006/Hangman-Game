# Hangman-Game
A simple text-based Hangman Game developed using Python. This project allows users to guess letters to find a hidden word with limited attempts. It demonstrates basic Python concepts such as loops, conditions, lists, strings, random module, and user input handling.

## Features

* Random word selection
* Letter guessing system
* Wrong guess limit
* Win/Lose conditions

## Technologies Used

* Python
* Random module

## How To Run

```bash
python hangman.py
```
